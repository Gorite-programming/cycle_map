# 気象庁 地域定義データ (JMA Area Definition Data)

本ディレクトリに格納されている以下の JSON ファイルは、気象庁ホームページから取得した地域コード定義です。

- `area.json`: 気象庁の全国地域定義階層（centers, offices, class10s, class15s, class20s）
  - 取得元: `https://www.jma.go.jp/bosai/common/const/area.json`
  - 取得日時: 2026-10-16
- `forecast_area.json`: 天気予報区域とアメダス地点（気温等）の対応関係テーブル
  - 取得元: `https://www.jma.go.jp/bosai/forecast/const/forecast_area.json`
  - 取得日時: 2026-10-16

## 出典表示
出典：気象庁ホームページ (https://www.jma.go.jp/)
本データは気象庁利用規約（https://www.jma.go.jp/jma/kishou/info/coment.html）に基づき、利用条件に従って適切に加工・利用されています。
