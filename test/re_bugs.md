# 第3者視点でのUI/UX評価およびバグ報告 (re:bugs.md)

`cycle_map/test` (Androidアプリケーション) を実機(Galaxy S21)で動作確認し、UI/UXおよび機能面での評価を行いました。特に「Google MapsへのUI寄せ(3Dベクター)」を念頭に置いた改善点をまとめています。

## 1. 重大なバグ (Bugs)

*   **ナビゲーションルート(経路線)の非表示**
    *   **症状**: ナビゲーション実行中（ヘッダーに「〇〇m先右折」等の案内が出ている状態）であっても、地図上に進行すべき経路（青いルート線等）が描画されていない。
    *   **原因推測**: `VectorMapView.kt` におけるレイヤーの追加順序 (`routeLayer` を `buildings-3d` の下に追加している等) や、Z-orderの不整合によって、ルート線が道路レイヤーや3D建物の下に隠れてしまっている可能性が高いです。
*   **通知バナーのUI被り（Z-order/レイアウト）**
    *   **症状**: 「GPS信号が弱まっています」等の紫色の通知バナーが画面上部に出現した際、検索バーの下にあるPOIチップ（コンビニ、道の駅など）に完全に被ってしまっている。
    *   **原因推測**: Compose側のレイアウト設定（Box内の配置）で、バナーが他のUI要素の配置スペースを押し下げるようになっていない、あるいはZ-orderとマージンが正しく設定されていないためです。

## 2. UI/UX 懸念点 (Google MapsへのUI寄せに向けた改善点)

*   **ダークテーマUIの重さと浮き（Light/Darkモードの不一致）**
    *   **現状**: マップ本体（背景や道路）は白・グレー基調の明るいデザインである一方、検索バー、サイドコントロールボタン群、ナビゲーションヘッダー、ボトムシートなどが全て「ダークネイビー（#1D2A43等）」で統一されており、画面全体として重く、浮いた印象を与えます。
    *   **改善案**: Google Mapsに寄せるため、ライトモード時はこれらのコンポーネントを**白背景＋軽いシャドウ（Drop Shadow）**に変更し、マップと調和したクリーンな見た目にする必要があります。
*   **2D/3Dトグルボタンの自己主張が強すぎる**
    *   **現状**: 左下に巨大な「2D 平面（ピンク）」や「3D 鳥瞰（ブルー）」ボタンが配置されており、地図の視認性を損ねています。
    *   **改善案**: Google Mapsのように、直接的な巨大ボタンは廃止するか目立たなくすべきです。2本指スワイプでのピッチ変更に依存させるか、右側のコントロール群（コンパス等の列）に**小さな「3D / 2D」アイコン**として統合するデザインが理想的です。
*   **サイドコントロールボタンのグループ化**
    *   **現状**: 画面右側の「レイヤー、GPS現在地、ズーム(+, -)」が1つの大きな角丸長方形のパネルにまとめられています。
    *   **改善案**: Google Mapsのように、**独立した白い円形（または角丸）ボタン**を縦に配置するスタイルに変更し、地図が透けて見える領域を増やします。
*   **3D建物の立体感・陰影 (Lighting / Shadows) の不足**
    *   **現状**: 3D建物 (`buildings-3d`) が `#E9EAEF` の単色でのっぺりしており、Google Mapsの3D表示のようなリッチな立体感がありません。
    *   **改善案**: `style.json` (例: `protomaps_light.json`) の `light` プロパティ（`intensity`、`position`）を調整し、太陽光の方向と影（Shading）を強調します。また、必要に応じて `fill-extrusion-color` に高度に応じたグラデーションを強めるか、環境光を計算に入れた色味に調整します。
*   **ナビゲーションヘッダーの視認性**
    *   **現状**: フローティングカード（角丸）として配置されていますが、背景がダークカラーで情報が少し埋もれがちです。
    *   **改善案**: 案内中は画面上部の横幅いっぱいに広がる**グリーンベースのパネル**に変更し、進行方向の矢印と距離を白字で極大表示することで、サイクリング中の視認性を高めます（Google MapsのアクティブナビゲーションUI）。
