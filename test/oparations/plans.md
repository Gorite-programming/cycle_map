## 2. オフライン/オンライン動作設計(最重要)

**原則**: 評価はオフライン(機内モード)前提で行う。オンラインは「同じ画面に追加情報を足す」だけで、**レイアウトを変えない**(要素の出し入れで画面がガタつかないこと)。

### 2.1 接続状態の管理(新規)

- 新規: `app/src/main/java/com/gorite/cyclemap/net/ConnectivityState.kt`
  - `sealed interface Link { Offline, OnlineMetered, OnlineUnmetered }` を `StateFlow` で公開(`ConnectivityManager.NetworkCallback`)。
  - 「接続あり」でも到達性を検証(`NET_CAPABILITY_VALIDATED`)。検証できなければ `Offline` 扱い。
- 新規: `app/src/main/java/com/gorite/cyclemap/net/OnlineFeatureGate.kt`
  - 設定「オンライン補助を使う」(既定 **OFF**)かつ `OnlineUnmetered`(またはユーザーがモバイル通信を許可)の時のみ `enabled=true`。
  - **オンライン機能の呼び出しはすべてここを経由**する。直接 `HttpURLConnection` を使わない。
- **タイムアウト**: 3秒。失敗は握りつぶさず `FeatureResult.Unavailable(reason)` を返し、UIは**静かに**オフライン表示へ戻る(エラーダイアログ禁止)。

### 2.2 機能別: オフライン表示 vs オンライン表示

| 機能 | オフライン(既定・必須) | オンライン(任意の上乗せ) | UI上の差の出し方 |
|---|---|---|---|
| 地図タイル | 端末内ベクタータイル/MBTiles(`protomaps_*`、地理院キャッシュ) | 地理院タイル/ベクターCDNで**不足タイルのみ補完** | 差なし。未取得域は薄いグリッド+「オフライン範囲外」の小チップ |
| 地図スタイル | 同梱 `*.json` + `sprites` | 同じスタイル。更新があればバックグラウンドで差替 | 見た目は同一 |
| 経路探索 | 端末内 A*(`.graph`) | 任意: 実交通の遅延係数のみ取得(§B6) | ルート線は同一。所要時間に「混雑考慮」バッジのみ追加 |
| 所要時間 | 時間帯別推定プロファイル(ローカル) | 実測遅延で補正 | 数値の下に小さく「推定」/「リアルタイム」 |
| 検索 | `*.search.db`(LIKE互換、FTS5不要) | 任意: 営業中/臨時休業などの最新情報を補足 | 結果カードの「営業中」表示は、**最終取得時刻が24h以内**の時だけ。それ以外は営業時間の静的表示 |
| POI詳細 | 名称/住所/カテゴリ/営業時間(静的) | 写真・口コミは**表示しない**(Google非依存方針)。代わりに自前メモ/お気に入り | オンラインでも要素を増やさない |
| 住所逆引き | `ReverseGeocoder`(ローカルDB) | なし | 同一 |
| 標高 | `ElevationRepository`(ローカルDEM) | なし | 同一 |
| 天気/風 | 非表示(スロット自体を作らない) | 任意: 風向・風速を地図上のチップに表示(自転車に有用) | オンライン時のみ右上にチップが**フェードイン**(レイアウトシフトなし、予約領域を持つ) |
| 公共交通 | 鉄道路線・駅は地図レイヤーとして表示(静的) | なし | 同一 |
| 音声案内 | 端末TTS(`VoiceGuidance`) | なし | 同一 |
| データ更新 | 手動で ZIP 導入(`push_data.sh` / 内部ストレージ) | 任意: パッケージ更新の確認/ダウンロード(Wi-Fi限定が既定) | 設定画面の「データ」にのみ出す |

### 2.3 状態表示ルール

- 画面上部に**常駐バナーを出さない**(再発防止: 既知の通知バナー被り)。
  - オフライン時は、レイヤーボタン付近の小アイコン(雲に斜線)とツールチップのみ。
  - 「オンライン補助ON」時は、小アイコンが色付き。切替時にレイアウトを動かさない。
- **全てのUIはオフラインで機能完結**していることをテストで保証する(§8 `OfflineParityTest`)。

**P1-1. 移動モード(B1)**
- `routing-core` に `TravelMode { Bicycle, Walk, Car }` を追加。各 `CostModel`(`CyclingCostModel` の最小倍率 0.90 は A* ヒューリスティック下限なので維持。`LazyMappedRoadGraph` と同期)。
- `Car` は `motorway` を許可、`Bicycle` では従来通り除外。`Walk` は `footway/path/steps` を許可。
- 複数ルート: ペナルティ法(1本目の辺コストを +30% して再探索、類似度 >70% は棄却)で最大3本。
- ゴールデンテスト: 既存テストグラフで、各モード×3経路のコスト/距離を JSON で固定(`routing-core/src/test/resources/golden/`)。

**P1-2. 所要時間(B1/B6)**
- `TravelTimeEstimator`(新規): 速度 = 基本速度(モード別)× 勾配補正 × 道路種別補正 × 時間帯補正 × 信号/横断ペナルティ。
- 時間帯プロファイル(平日朝夕、休日)は **JSONリソース** に外出しし、オフラインで動く。
- `net` 経由の実交通補正は §2.2 の通り、**乗算係数のみ**(ルート形状は変えない)。取得失敗は係数 1.0。

**P1-3. リルート(B2)**
- `OffRouteDetector`: 閾値 30m(速度に応じて可変)、連続3サンプルで確定。再探索は別スレッド、結果到着まで旧ルートを表示し続ける(消さない)。
- テスト: 逸脱GPXを使い、再探索成功率 ≥ 98%、レイテンシ <3秒。

**P1-4. 車線案内・案内強化(B3)**
- `osm-importer` で `lanes`、`turn:lanes`、`destination`、`ref` を `.graph.idx` に追加格納(バイナリ互換のためバージョン番号を上げ、旧版を検知して再生成を促す)。
- `Instruction` に `lanes: List<LaneHint>?`、`signpost: String?`、`secondManeuver` を追加。`GoogleNavHeader` に車線バー、次の次の案内を表示。
- 音声: 距離別トリガ(500/200/50m)、「その先、○○」を連結(`VoicePhraseCatalog` 更新)。
- 注意: `LazyMappedRouting.readEdge()` の 2GB 超オーバーフロー(`offset.toInt()`)に触れる場合は、`Long` で修正しテストを追加。

## 7. P2/P4/P5/P6 の仕様

### P2: 検索・POI(B4, B5)
- `SearchHelper.kt`(1,355行)から `search/` パッケージへ分割(クエリ正規化/ランキング/DAO)。
- オートコンプリート: 入力1文字から候補、`search_text` 列の前方一致+部分一致、**現在地までの距離でブースト**。<120ms をテストで検証。
- ジャンル検索: カテゴリ辞書(日英)。「近くのコンビニ」「駅」「トイレ」に対応。
- `opening_hours` パーサ(OSM形式の主要サブセット: `Mo-Fr 09:00-18:00; Sa off`、`24/7`、`PH off`)を実装し、**単体テスト 30ケース以上**。
- POIカード: 「営業中/営業時間外」は、静的営業時間から**端末時計で判定**(オフライン可)。判定不能なら何も出さない(誤表示より非表示)。
- データ側(`sandbox/data-tool`)で `opening_hours`/`phone`/`website` 列を保持するようスキーマ拡張。**既存DBと互換**(列が無い場合は null として動作)。

### P4: ナビ・経路選択・詳細シート(F5, F6, F7)
- 場所詳細シート: 3段アンカー(`PEEK 120dp / HALF 50% / FULL`)、慣性スワイプ、地図のPOIタップ→ピーク表示。
- 経路選択: 複数ルートを同時描画(選択=濃青、代替=淡灰)、タップで切替、カード(所要時間・距離・標高差・「最短/平坦/安全」ラベル)。
- ナビ: ヘッダー(全幅緑、大矢印、残距離、車線バー、次の次)、フッター(ETA/残時間/残距離)、**概要ビュー**(全体表示)、**到着画面**、ミュート。画面常時点灯、省電力時のカメラ更新間引き(`CameraMotionPolicy`)。
- 既知の再発防止: ルート線は `roads` の上、`buildings-3d` の下(または 3D 時は地面ドレープ)に必ず描画。レイヤー順テストを追加(`styleLayerOrderTest`)。

### P5: モーション・アクセシビリティ・テーマ(F1, F8, F9)
- ダークテーマ(`protomaps_dark.json`)と UI の自動切替を、**日没基準(オフラインで天文計算)**で実装(`DayNightManager` を拡張、通信不要)。
- 全文字列を `res/values/strings.xml` に移動(日本語既定、英語 `values-en`)。
- `contentDescription` 付与、フォントスケール 1.3x のスクリーンショットテストで崩れなし。

### P6: データ管理・オンライン補助(B7, B8)
- 「データ」設定画面: インストール済み県、容量、整合性(SHA-256)、削除、再導入手順の表示。
- 任意のオンライン更新(Wi-Fi限定が既定)。ダウンロードは再開可能、完了後に SHA-256 検証、失敗時は既存データを**絶対に消さない**(一時ファイル → 検証 → アトミックrename)。
- 追跡: GPXインポート/エクスポート、走行履歴の整理、GPSフィルタ(カルマン等)を `tracking/` に追加しテスト。
