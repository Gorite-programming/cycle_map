# 修正プラン (plans.md)

次のAIエージェントが効率よく作業できるようにするための、バグ修正およびUI/UX改善（Google Maps風へのデザイン変更）のステップバイステップの計画です。

## フェーズ1: 重大バグの修正 (機能の正常化)

1.  **ナビゲーションルート非表示バグの修正**
    *   **対象ファイル**: `test/app/src/main/java/com/gorite/cyclemap/VectorMapView.kt`
    *   **作業内容**:
        *   MapLibreの `style.addLayer` 関連のコードを確認。
        *   `routeLayer` が `buildings-3d` の下ではなく、少なくとも道路 (`roads`) よりも上、かつ視認可能な適切な階層に追加されるように順序を修正する。
        *   ルート描画用の `LineLayer` (あるいはナビ中の描画設定) のプロパティを見直し、3D表示時でも地面の上に適切に表示・またはポリゴンに追従するように修正する。
2.  **通知バナーのレイアウト被り修正**
    *   **対象ファイル**: ComposeのUIファイル (`MainActivity.kt` などのメイン画面構成部分)
    *   **作業内容**:
        *   「GPS信号が弱まっています」等の通知バナー (Toast/Snackbar/Banner) を表示するBoxやColumnのZ-order(zIndex)を上げ、必要に応じて上部に適切なパディングを持たせることで、POIチップ等に被らないようにレイアウトを修正する。

## フェーズ2: Google Maps風UI/UXへのリファクタリング (3Dベクター)

1.  **UIコンポーネントのライトモード(白背景化)対応**
    *   **対象ファイル**: ComposeのUIファイル（検索バー、ボトムシート、ボトムナビ、ヘッダーなど）
    *   **作業内容**:
        *   全体的に使われているダークネイビー色 (`#1D2A43` など) を、白 (`Color.White` 等) または非常に明るいグレーに変更する。
        *   Google Mapsのような浮遊感を出すため、`elevation` (Shadow) を適切に設定する (`Modifier.shadow(8.dp, RoundedCornerShape(...))` など)。
        *   フォントカラーをダークグレー・黒に変更し、コントラストを確保する。
2.  **巨大な「2D/3D切り替えボタン」の廃止・統合**
    *   **対象ファイル**: `VectorMapView.kt` または関連するComposeコントロールパネルUI
    *   **作業内容**:
        *   画面左下の巨大なピンク・ブルーのトグルボタンを削除する。
        *   代わりに、右側のフローティングボタン群（後述）に小さな「3D / 2D」アイコンボタンとして組み込むか、2本指スワイプによるピッチ操作に完全依存させる。
3.  **右側フローティングコントロールの分割 (Google Mapsスタイル)**
    *   **作業内容**:
        *   現在一つにまとまっている角丸長方形のグループパネルを解体する。
        *   「コンパス」「レイヤー切替」「現在地(GPS)」「ズームイン(+)」「ズームアウト(-)」の各ボタンを、独立した白い円形または角丸のボタン (`FloatingActionButton` や `IconButton` ＋丸背景) にし、縦に並べて配置する。
4.  **ナビゲーションヘッダーの刷新**
    *   **作業内容**:
        *   現在の「浮いているダークな角丸カード」から、画面上部にピッタリくっつく「全幅のグリーンパネル」に変更する。
        *   矢印（右折・左折など）と距離（残り〇〇m）を、白抜きで巨大なフォントサイズにして強調する。
5.  **3D建物の見た目の改善 (陰影・Lightingの調整)**
    *   **対象ファイル**: `test/app/src/main/assets/styles/protomaps_light.json` (など使用中のスタイル定義ファイル)
    *   **作業内容**:
        *   `light` プロパティの `intensity` (例: 0.3 → 0.6〜0.8程度) や `position` を変更し、建物にはっきりとした影と明るい面ができるように調整する。
        *   `fill-extrusion-color` を少し明るい色に変更し、環境光とのバランスをとることで、のっぺりとした単色感を解消する。

## 実装時の注意点
*   作業中は随時 `adb exec-out screencap -p > check.png` 等で実機上の表示を確認しながら進めること。
*   3Dベクターに限定した改善であるため、MapLibre固有のレイヤー仕様 (`fill-extrusion`) とComposeのUIレイヤーの分離を意識して修正を行う。
