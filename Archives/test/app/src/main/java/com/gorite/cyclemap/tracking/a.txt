結論から言うと、標準のBLE心拍サービスとしてはBip6単体からは直接取れません。

Bip6の仕様書見ると「周辺Bluetoothデバイスへの接続」に対応してるのは、Bip6が**心拍ベルトやパワーメーターなどの外部センサーを受け取る側(central)**としてで、逆にBip6自身が汎用アプリ向けに標準BLE Heart Rate Service (0x180D) をbroadcastする仕組みではないです。Zeppアプリとの通信は独自(非公開)プロトコルなので、普通に自作アプリからGATT接続してもデータは拾えません。

選択肢は2つ:

Gadgetbridge経由で拾う — Amazfit/Zepp系デバイスの独自プロトコルをリバースエンジニアリングしたオープンソースの代替コンパニオンアプリ。Bip6のリアルタイム心拍取得に対応してる実績があるので、これをベースに(または参考にプロトコル解析して)自作アプリに組み込む方向
別途BLE心拍ベルトを買う — Bip6はそのまま時計として使い、心拍だけは標準BLE HRSを喋る安い胸ベルト(Polar H10とか)を別に用意する。実装は圧倒的に楽（標準プロファイルなので数十行で読める）
正直、②の方が実装コストは低いです。①はGadgetbridgeのコード読み込んでプロトコル理解するところからなので結構な工数になります。どっちの方向で進めます?

転倒検知、入れる価値ありです。実装は難しくなくて:

加速度の急激なスパイク(通常走行のG変化を超える値)を検知
その直後に数秒間静止(加速度がほぼ変化しない)が続いたら「転倒の可能性」と判定
誤検知(段差でのバンプとか)を減らすため、スパイク+静止の両方が揃ったときだけアラート

package com.gorite.cyclemap.tracking

import android.location.Location
import java.io.File
import java.text.SimpleDateFormat
import java.util.Date
import java.util.Locale
import java.util.TimeZone

/**
 * Collects timestamped track points and serializes them as GPX 1.1.
 * Pure formatting logic lives in [GpxWriter] so it can be unit-tested on the JVM.
 */
class GpxRecorder {
    private val points = mutableListOf<GpxPoint>()

    val pointCount: Int get() = points.size

    fun addPoint(location: Location) {
        points.add(
            GpxPoint(
                latitude = location.latitude,
                longitude = location.longitude,
                elevationMeters = if (location.hasAltitude()) location.altitude else null,
                timestampMillis = location.time,
            ),
        )
    }

    fun writeToFile(file: File): File {
        file.parentFile?.mkdirs()
        file.writer().use { it.write(GpxWriter.write(points)) }
        return file
    }
}

data class GpxPoint(
    val latitude: Double,
    val longitude: Double,
    val elevationMeters: Double?,
    val timestampMillis: Long,
)

object GpxWriter {
    private val gpxTimeFormat = SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss'Z'", Locale.US).apply {
        timeZone = TimeZone.getTimeZone("UTC")
    }

    fun write(points: List<GpxPoint>): String = buildString {
        append("<?xml version=\"1.0\" encoding=\"UTF-8\"?>")
        append('\n')
        append("<gpx version=\"1.1\" creator=\"CycleMap\" xmlns=\"http://www.topografix.com/GPX/1/1\">")
        append('\n')
        append("  <trk><name>CycleMap recording</name><trkseg>")
        append('\n')
        for (p in points) {
            append("    <trkpt lat=\"").append(formatCoord(p.latitude))
                .append("\" lon=\"").append(formatCoord(p.longitude)).append("\">")
            if (p.elevationMeters != null) {
                append("<ele>").append("%.1f".format(Locale.US, p.elevationMeters)).append("</ele>")
            }
            append("<time>").append(gpxTimeFormat.format(Date(p.timestampMillis))).append("</time>")
            append("</trkpt>")
            append('\n')
        }
        append("  </trkseg></trk>")
        append('\n')
        append("</gpx>")
        append('\n')
    }

    private fun formatCoord(value: Double): String = "%.7f".format(Locale.US, value)
}
