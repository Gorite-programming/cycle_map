# Third-party map style assets

- Japanese label layers are generated by `sandbox/vector_test/pipeline/generate_re_test_label_layers.js` using `@protomaps/basemaps` 5.7.2. The library is BSD-3-Clause; its visual design is CC0. Its icon layers use MIT-licensed Tangram icons. See `protomaps-basemaps-BSD-3-Clause.md` and `tangrams-icons-MIT.txt`.
- The packaged Protomaps glyph ranges (`fonts/Noto Sans Regular/*.pbf`) are from `protomaps/basemaps-assets/fonts/Noto Sans Regular/`. Noto Sans is licensed under SIL Open Font License 1.1. Ranges 0-255, 12288-12543, and 65280-65535 are packaged; MapLibre Native generates CJK Unified Ideographs locally from the Android `sans-serif` family. See `protomaps-fonts-OFL.txt`.
- The light/dark MapLibre sprite sheets are from `protomaps/basemaps-assets/sprites/v4/`. Their icons are derived from the MIT-licensed Tangram icons. See `tangrams-icons-MIT.txt`.
- The pre-existing `ofm*` sprite files are byte-identical to OpenFreeMap's official `https://tiles.openfreemap.org/sprites/ofm_f384/ofm` assets. OpenFreeMap Styles identifies the included Maki POI icons as CC0 and the style repository as MIT. See `openfreemap-styles-MIT.md`.

The app's map data attribution remains governed by the map package and the in-app map information dialog; these style asset notices do not replace map data attribution.
