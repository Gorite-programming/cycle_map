# Google Maps 互換度 採点台帳 (`re_test/scorecard_90percent.md`)

## 1. 計算方式
- フロント (F1〜F9): 重み合計 82
- バック (B1〜B9): 重み合計 90
- `フロント% = Σ(重み × 得点) / 82`
- `バック% = Σ(重み × 得点) / 90`
- `全体% = (フロント% + バック%) / 2`
- **目標**: フロント ≥ 92%, バック ≥ 88%, 全体 ≥ 90%
