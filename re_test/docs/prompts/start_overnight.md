> そのまま最初の指示として渡す。詳細ルールは `overnight_P0_to_P7.md` にある。

---

これから就寝するため、**朝まで応答できません**。P0 の内容はすでに把握済みですが、以下を踏まえて **P0 から P7 まで自律的に**進めてください。

1. まず `re_test/prompts/overnight_P0_to_P7.md` を**最初から最後まで読み**、そこに書かれたルール(§1 絶対に守ること、§2 進め方、§3 最終処理)に従う。`P0_prompt.md` にある「段階1で停止して承認を待つ」は**承認済み**として扱い、停止せず P0 の実装に進んでよい。
2. `re_test/NIGHT_LOG.md` を作り、開始時刻を記録する。以後、各タスクの開始・完了・失敗・保留のたびに追記する。
3. **Git 操作はしない**。変更は `re_test/` 配下のみ。`application/`・`test/`・`AGENTS.md` は読み取り専用。
4. 質問で止まらない。詰まったら 3 回までで保留にして、依存しない別タスクへ進む。
5. 実行していないテストを成功と書かない。実機で確認できなかったものは「未確認(実機)」と書く。
6. 全フェーズが終わるか進められなくなったら、`re_test/FINAL_REPORT.md` を作って停止する。

最初のタスクは P0-1 です。始めてください。
