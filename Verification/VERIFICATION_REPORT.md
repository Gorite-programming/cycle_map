## 4. CycleMap の優位点（Google Maps を超える点）

1. **完全100%オフライン自律稼働**:
   - 地図描画、地名・POI検索（数十万件）、A*ルーティング、リアルタイム標高プロファイル計算、音声案内が**機内モードでも一切の機能低下なく動作**。
2. **サイクリスト専用の高度なルーティング**:
   - 単なる最短距離ではなく、「平坦優先」「坂道優先」の勾配コスト考慮ルーティングを瞬時に実行。
   - 標高プロファイル（推定）グラフにより、これから走る区間の上り・下りの勾配変化を視覚的に把握可能。
3. **専門地図レイヤーのワンタップ循環**:
   - 3Dベクター（昼・夜）だけでなく、サイクリストに不可欠な「国土地理院標準地図（等高線）」や「地形起伏陰影図（DEM）」をワンタップで切り替え可能。
4. **回廊保存（Corridor Cache）**:
   - 探索したルート周辺の地図タイルをワンタップで事前一括キャッシュ可能。
5. **走行ログ（GPX）管理**:
   - アプリ単体でライドの記録開始・停止、距離・平均速度の蓄積、GPX保存に対応。

## 5. 93.2% から 100% への改善推奨ポイント

1. **ナビ中のテキスト文言の自然言語化**:
   - 「次の案内: ↱ single-branch」の `single-branch` など、OSMグラフの内部構造名が生で露出している箇所を「分岐」「交差点」などの自然な日本語表現にマッピングする。
2. **ナビHUD画面のコントロール拡充**:
   - Google Mapsと同様に、ナビ案内中の画面上に「現在速度（スピードメーター）」や「コンパス（北固定/進行方向切替）」のフローティングUIを追加する。
3. **検索画面のクイックショートカット**:
   - 「自宅」「職場」「お気に入り」へのワンタップ遷移チップを検索画面上部に常設する。
4. **地点詳細シートの拡充**:
   - ピンタップ時に、施設の詳細情報（営業時間、電話番号、設備等）をハーフモーダルで閲覧できるシートの拡張。
