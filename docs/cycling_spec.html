概要

Android端末単体で完結し、通信環境に依存せずに動作する、完全オフラインのサイクリング用マップ・ナビゲーションアプリ。地図表示からルート案内、走行記録、センサーによる走行データ取得までを一つのアプリでまかなう。

地図データのダウンロード範囲は、初期スコープとして中国地方を対象とする。

センサー連携

micro:bitを使った速度・ケイデンス・転倒検知の自作センサー構成。

メイン ・ 車体側

micro:bit v2

  • ホイール＋ペダルにリードスイッチ＋磁石を取り付け、パルスカウントで速度・ケイデンスを算出
  • 加速度センサーで転倒検知(スパイク＋直後の静止で判定)
  • BLE UARTでアプリへストリーミング

サブ ・ ハンドル側

micro:bit v1.5

  • ハンドル取り付けの記録開始 / 停止リモコン
速度算出ロジック 低速時はmicro:bitのセンサー値を優先し、それ以外はGPSとの平均値を使用する。
心拍(Amazfit Bip 6) ― 保留中 Gadgetbridge側のプロトコル解析が必要なため、連携は一旦保留。

アーキテクチャ構成イメージ

センサー・GPSからの入力がアプリコアを経て、案内・記録として出力される流れ。

入力

  • GPS位置情報
  • micro:bit(BLE UART)
→

アプリコア

  • GraphHopperルーティング
  • 記録エンジン(GPX)
  • 統計・センサー統合計算
→

出力

  • 音声案内(VOICEVOX)
  • 地図・統計UI表示
  • GPXファイル保存
